# Maintenance entry points

The [maintenance guide](../../../docs/maintenance/README.md) owns the current workflow.

Use [feature notes](../../../docs/features/README.md) for shipped behavior, the [handbook](../../../docs/handbook/README.md) for code and architecture, and the upstream section of the maintenance guide for integration. Update the responsible facts when they change. Ordinary fixes use the PR; there are no required cards, decision templates, translation confirmations or archive certificates.
