# 官方 DeepSeek Harness Desktop 与本项目对比

核对日期：2026-09-25（Asia/Shanghai）。本次为发布元数据、文档和源码调研，**未安装或实机体验官方安装包**，不据此判断速度、内存、稳定性或完整跨平台体验。

## 比较基线

- 官方 GitHub `master` 当前 SHA 为 `477b4f420553e8a52c2fbccc464d7561b239c443`，与本项目 `vendor/harness-upstream.json` 的 `dsh-v0.1.7-rc.2` pin 相同。官方 Desktop manifest 版本也是 `0.1.7-rc.2`。因此，本轮比较不是“官方新内核对我们的旧内核”，而是同一上游基线的两套桌面集成。[官方提交](https://github.com/deepseek-ai/deepseek-harness/commit/477b4f420553e8a52c2fbccc464d7561b239c443)、[官方 manifest](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/apps/desktop/package.json)、[本项目 pin](../../vendor/harness-upstream.json)
- 官方最新 GitHub release `dsh-v0.1.7-rc.2` 于 2026-09-24 14:10:21 UTC（北京时间 22:10:21）发布，`prerelease=true`，该 release 的 assets 为空。查询 `desktop-v*` refs 也未返回记录。官方已有桌面源码与发布说明，但**本轮未确认公开桌面安装包的独立版本及下载入口**；不把 CLI/仓库预发布标签等同于已验证的桌面二进制发布。[release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.2)、[release API](https://api.github.com/repos/deepseek-ai/deepseek-harness/releases/tags/dsh-v0.1.7-rc.2)、[desktop refs API](https://api.github.com/repos/deepseek-ai/deepseek-harness/git/matching-refs/tags/desktop-v)
- 本地桌面壳的 manifest 为 `0.3.3`，产品名为 Whale Isle；这是桌面产品自己的版本，不能与官方 `0.1.7-rc.2` 数字直接比较新旧。本地工作树包含用户尚未提交的实现，本报告按当前工作树核对，不将其全部称为已公开发布。[本项目 manifest](../../package.json)
- 已将主要官方文档的本地 vendored 文件计算 Git blob hash，与 GitHub tree API 比对。Desktop README、manifest、tray、Browser webview 决策、终端、Files、workspace-files、workspace-changes、SSH 文档匹配。`ui-deliverables/README.md` 有本地修改，官方事实使用固定 SHA 的在线原文；不能把 vendored 所有内容无条件当作官方原版。

## 产品差异

| 方面 | 官方 Desktop（固定 SHA 源码） | 我们的当前桌面端 | 判断 |
|---|---|---|---|
| 产品结构 | Electron 包装完整官方 Web；用 Electron RunAsNode 子进程运行 Host，主页面从 `dsh-app://app/` 的打包资产启动；壳与 dsh 是一个版本单元。[架构](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/.agents/notes/implemented/architecture/2026-09-10-desktop-web-wrapper.md) | 自己的 Electron 壳，使用随包 Node 启动 `dsh web`，通过 loopback Web UI 和 `BrowserView` 加载，并叠加桌面桥接与专有插件。[启动](../../src/main/dsh.js)、[窗口](../../src/main/window.js) | 同源 Web 内核，桌面宿主实现不同。vendor 包含官方 `apps/desktop` 不表示我们的打包流程采用了它。 |
| 数据与插件 | 与 CLI 共享 `$DSH_HOME` 下支持的会话、设置、凭据与工作区；独占 `profiles/desktop` 的可执行包、插件激活、锁文件及 `node_modules`，启动不运行 pnpm 安装核心。[运行时隔离](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/.agents/notes/implemented/architecture/2026-09-08-desktop-bundled-runtime-and-external-plugins.md) | 桌面数据使用 `%APPDATA%/Deepseek-Harness-Desktop/dsh-home`，跑 `profiles/web`，与 CLI 默认 `~/.dsh` 分离；终端中的 CLI 也不被注入桌面 home。[数据目录](../handbook/modules/dsh-home.md) | 官方强调 CLI/桌面数据连续使用；我们强调桌面隔离，切换官方不能默认认为数据自动可见。 |

| Terminal | 官方已有 xterm.js PTY、多终端、shell 选择、改名、重连/接管；折叠或换页继续运行，关闭终端 tab 请求结束进程；不把用户终端输出加入模型输入。[官方终端](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/packages/client/ui-sidebar-terminal/README.md) | 底部终端抽屉/Surface、node-pty + Ghostty 网格，支持选区送 Composer；关抽屉、关 tab、切会话不 kill，垃圾桶/app 退出等清理进程。[我方终端](../handbook/modules/terminal.md) | 双方都有真终端，区别是呈现位置、引擎、送对话及生命周期；不能再把 PTY 本身视为独有。 |

## 必须保留的边界

1. **逐轮 Diff 与仓库 Diff 是不同能力。** 官方逐轮快照存在 Host 当前 Session 生命周期内，Host 重启后原卡片/比较不保证保留。我们 vendored 的 `ui-deliverables` 也包含该上游能力，且本地手册记载原生 sidebar 承接兼容资源；本轮未实机确认这些入口，所以不能由自研 `ui-diff` 的“无 turn-diff”推导出整个我方产品完全没有逐轮审阅。[官方 recorder](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/packages/deliverables/workspace-changes/README.md)、[我方路由](../handbook/modules/surfaces.md)
2. **官方已有 SSH 底层。** 官方 `ssh/fs-ssh/subprocess-ssh/sandbox-ssh` 支持远程文件、进程与终端，面向 headless/custom profiles；文档明确 Web workspace 仍需要独立集成。我们则做了桌面远程工作区入口与手机接入，但本地远程手册仍有真实 SSH 验收 `NOT RUN`，手机公网/物理设备验收未完成，不能称为已成熟领先。[官方 SSH](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/docs/subsystems/ssh.md)、[我方远程](../handbook/modules/remote-workspaces.md)、[我方手机](../handbook/modules/mobile-remote.md)
3. **Browser 有源码不等于全面验收。** 官方 webview 决策明确保留真实 Electron 附着、遮挡、焦点、平台样式、存储隔离等运行时验证缺口；我方媒体/远程能力也不能仅凭存在源码就宣称已验证稳定。[官方 Browser 验证边界](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/.agents/notes/implemented/feature/2026-09-20-desktop-browser-webview.md#consequences)
4. **部分上游文档句子滞后。** Desktop README 的旧快捷键段仍说 Windows 关闭最后窗口即退出，与同文件开头、rc.2 release 和 2026-09-23 已实现决策冲突；报告采用后者及 `tray.ts`。同理，不采用 README 中与现行登录实现冲突的旧限制段。[托盘源码](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/apps/desktop/src/tray.ts)、[rc.2 release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.2)

## 判断与后续取舍

官方桌面端已经覆盖“把 dsh 装成一个可用桌面应用”的核心价值：Electron 宿主、内置运行时、插件管理、Files/Browser/Terminal、逐轮审阅、后台和恢复。我们的价值应落在 **Git 操作工作流、Files/Browser/Terminal 与对话之间的连接、Bots 和个性化体验**，而不是重复证明“dsh 可以有桌面壳”。这是一项基于上表功能范围的产品判断，不是实测性能结论。

值得优先评估复用的是官方的 **profile/runtime 分离、Office 依赖自给、签名/更新/失败恢复**。若进一步考虑替换桌面底座，应先做一份适配清单：我方 main/preload 桥接、Git/PTY/Browser 的宿主接口、独立 home 的迁移、以及所有专有 UI 插槽能否保留。当前守卫登记 19 个桌面专有包、18 个 composition row、96 条 marker（覆盖 92 个不同文件）；这些是守卫登记规模，不是完整 patch 文件数，直接换壳不是无成本操作。[fork 登记](../../src/shared/harness-desktop-forks.js)

本次仅新增调研文件，未改产品代码、启动配置、用户数据或安装包。
