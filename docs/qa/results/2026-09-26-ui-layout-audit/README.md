## 真问题（功能态，非布局错位）

1. **远程工作区 `HTTP 400`**（`s-远程工作区.png`）：页面顶部红字错误。同源根因：「远程」页显示监听地址 `172.24.64.1` 已失效（EADDRNOTAVAIL，网卡断开或地址变更）→ dshd-remote daemon 起不来 → 远程工作区 API 400。建议动作：设置→远程→监听范围改选有效地址；属真实状态错误而非渲染缺陷。
2. **关于页版本文案歧义**（`s-关于.png`）：显示「当前版本 0.3.3」+「已是最新版本 0.3.2」。开发版号高于最新发布号时文案读起来矛盾；语义上可解释为"最新正式版=0.3.2，当前=0.3.3"，建议文案区分「当前」/「最新发布」。
