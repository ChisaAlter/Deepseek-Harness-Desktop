# 手机远程 · 生产交付实机全量用例

对照源：[docs/features/mobile-remote.md](../features/mobile-remote.md) MUST 矩阵。桌面真相是正在跑的 `dsh web` 项目侧栏 + 同一进程 `session.list` / `workspace.list`，不是 ACP `fetchAgents`，不是本机另起的 SPA。

本表是 **即将生产交付** 的第二客户端门禁。发版表 [production-acceptance-test-cases.md](production-acceptance-test-cases.md) 的 `TC-REM-002` / `TC-REM-003` **以本表为细则**；本表任一条 **P0 Fail** ⇒ 发版表对应格不得 Pass，卡片 `last verified` 不得写「实机全量通过」。

## 本轮范围（先稳定 Web UI）

**本轮只验收手机浏览器 Web SPA（T1，局域网产品形态加 T2）。Android App / WebView（T3）整轨延后**，不进本轮可交付签字。产品卡里的 Android 路径仍有效，本表 T3 用例标 **Deferred**，不得删掉当「没有这轨」。

本轮「实机全量」= 外出二维码打开的公网 `/dshd` Web UI（及局域网模式下的 `:3180`）在 MUST 全表上稳定。APK 扫码、Compose 壳、`appassets.androidplatform.net` sticky **本轮不测、不宣称通过**。

## 0. 公约（先于所有用例）

### 0.1 轨道

| 轨 | 本轮 | 客户端 | 落地 origin（必须与桌面二维码一致） | 说明 |
| --- | --- | --- | --- | --- |
| **T1 外出 Web** | **必测** | 真机系统相机 → **手机浏览器** | `http://125.124.85.212:3389/dshd/` | 桌面远程 = 外出 / relay。nginx `app.js` 必须是本交付切面。 |
| **T2 局域网 Web** | 桌面为局域网时必测；外出模式 **禁止** 用本轨顶替 T1 | 真机系统相机 → 手机浏览器 | `http://<LAN>:3180/` | 外出模式不听 3180。 |
| **T3 Android** | **Deferred** | APK 应用内扫码 | `https://appassets.androidplatform.net` | Web UI 稳定后再开。本轮不得用旧 APK 或 T3 截图给 T1 打 Pass。 |

**本轮全量通过** = T1 上本表全部 P0 = Pass（桌面为局域网时 T2 同样）。只跑 Puppeteer、只 curl `app.js`、用 T3 顶 T1，都不是全量。

文中「每轨」在本轮 **只指 T1（及适用时的 T2）**，不含 T3。

### 0.2 桌面侧（所有轨道共用）

- 测的是 **用户正在用的那台桌面**：Electron 子进程 daemon 听 `:6767`，Harness 听 loopback `dsh web`。
- **禁止** 为了测通杀掉并另起一份 daemon、另起 `:3180`、另铸一份只给脚本用的落地页。
- 对照时桌面项目侧栏必须 **展开全部工作区**，并点开「展开其余 N 个会话」，直到侧栏里不再有折叠的活会话。
- Git / 提交类用例必须用 **临时空目录工作区**，禁止在产品仓（本仓库脏树）上 commit / push / publish。产品仓只允许只读核对照胶囊文案。

### 0.3 列表对照源（会话列表的唯一 Pass 标准）

对活会话集合 **L**：

```
L = session.list.items
    去掉 blank === true
    去掉 origin === 'dshbot'
    去掉 workspace.list.archivedSessionIds 中的 id
```

标题取 `projections.values.title` 去首尾空白；空则用 `sessionId` 前 7 位（与 SPA `sessionTitle` 同一规则）。

| 集合 | 定义 |
| --- | --- |
| **D** | 桌面项目侧栏 **可见行标题**（展开全部之后）。不含桌面用来当 New Session 的 blank 行。 |
| **P** | 手机抽屉 **可见行标题**（展开全部工作区头、滚到底）。分组模式下工作区头不算进 P；会话行才算。 |

**Pass 当且仅当 D = P（集合相等），且每条标题字符串全等。**

下列 **一律 Fail**，不论抽屉「看起来有东西」：

- `|P| ≥ 1` 但 `D ≠ P`（缺 1 条、多 1 条、标题截断/改写导致不等）
- 只断言「抽屉非空」「至少 N 条」「包含某几个关键字」
- 只读 DOM `textContent` / `querySelectorAll('.session b')`，截图里标题不可读（只剩 `⋯`、宽度被裁没、颜色对比失败）
- 用 `sessionId` 切片顶替桌面已有正式标题
- SPA 出现「加载更多」假分页（host `session.list` v1 一次返回全部）

**可见性（390×844 手机视口）：** 打开抽屉的截图中，每一行活会话标题至少能读出 oracle 标题的前 8 个字符（标题更短则全部可见）。工作区头、`+`、`⋯` 不得把标题挤出可视区域。

### 0.4 非法证据（出现则该格不得 Pass，本表不得勾可交付）

- `node tools/mobile-web-qa/run-qa.mjs`（fake host / fake daemon）
- `node tools/mobile-web-qa/run-live.mjs` 在 **外出模式** 下把 `appBaseUrl` 设成 `:3180`、或 bounce/替换 Electron daemon
- Puppeteer 打开 `127.0.0.1:3180` 却宣称测过 T1
- 公网 `/dshd/app.js` 仍含 `fetchAgents`、或不含 `hostCall` + `session.list`
- 源码树 SPA 已切面、但二维码仍指向未部署的旧 nginx（测了仓库、交了公网）
- Android 旧 APK 截图顶替 T1；本轮 T3 Deferred，APK 证据不得写入 T1 Pass
- 日志里打印完整 `#offer=`
- 停掉用户正在用的 Harness 来「测桌面端未启动」却不在报告里标造障；造障必须书面征得执行人同意

Puppeteer **可以对着真实 origin 做 rehearsal**（例如打开公网 `/dshd/#offer=` 且不 bounce daemon），结果只能写入 `docs/qa/results/<日期>/` 并标明 **Rehearsal，非 T1/T3 Pass**。

### 0.6 布局走查（WebUI 自身，不是「有按钮就算」）

对照 [design-language.md](../design-language.md) 手机例外：抄 `--dsw-alias-*` 与官方几何，**不是**把桌面四栏缩小。间距须为 4 的倍数。下列任一出现 ⇒ 该表面布局 **Fail**，不得用「功能还能点」过关。

**视口（每条布局用例都要拍）：**

| 档 | 尺寸 | 代表 |
| --- | --- | --- |
| 窄 | 360×640 | 小屏 Android |
| 标准 | 390×844 | 常见 iPhone 逻辑宽 |
| 大 | 430×932 | 大屏 |

安全区：刘海 / 底部 Home 条不得挡住发送、审批按钮、抽屉「新会话」。

**命中与间距（量截图或开发者工具盒模型，单位 CSS px）：**

| 规则 | 阈值 | Fail 例 |
| --- | --- | --- |
| 可点控件外包矩形 | **互不相交** | 权限 chip 压在附件 `+` 上 |
| 相邻可点中心距 | 竖屏 **≥ 36** | composer 左簇 `+` / 权限 / 计划挤成一坨 |
| 最小点击区 | **≥ 28×28**（发送 **≥ 34×34**） | 只有 16px 图标可点、周围无热区 |
| 文案 | 控件标签完整可读，禁止只剩省略或图标 | chip 显示「模…」或 Git 主按钮只剩「Com…」且无法点开看全文 |
| 抽屉会话标题 | 见 §0.3：前 8 字可见 | 一列 `⋯` |
| 遮罩层 | sheet / 审批 / 抽屉打开时，底层 composer **不得**可误触发送 | 审批未关就能发下一条 |
| 滚动 | 时间线、抽屉、sheet 列表可滚到底；底部控件不随内容顶出视口 | 发送键被顶到屏幕外 |

**必拍表面（缺一张不得宣称布局过）：** 连接页、已配对对话（空会话 hero）、已配对对话（有时间线 + composer）、抽屉全开、会话 ⋯ sheet、权限 sheet、模型 sheet、审批条出现时、Git 胶囊展开、新会话选工作区 sheet、设置页。

### 0.7 远程同步检查点（每场景步骤后都要做）

记作 **SYNC(操作)**。不做同步检查的步骤，该场景不得 Pass。

在手机完成操作、等会话 **idle**（停止运行、审批已决）后 **30 秒内**，桌面必须同时满足：

1. **列表：** 再跑一遍 §0.3，`D = P`。  
2. **当前会话：** 两边打开同一 `sessionId`；手机最新用户气泡原文 = 桌面该轮用户消息原文。  
3. **助手回复：** 桌面出现对应助手回合（允许流式未完时等 idle）；不得只有手机有、桌面无，或桌面有、手机时间线空白。  
4. **composer 状态：** 模型 / 思考档 / 权限预设 与桌面 ModelSelect、思考、Access **字符串级一致**（chip 停在「模型」未展开出 effort 而桌面已有思考档 → Fail）。  
5. **审批：** 一边允许或拒绝后，另一边 pending **消失**，不得一边还挂「等待审批」。

反向（桌面先操作）同样要 SYNC。只测手机本地 UI 变了、不看桌面，不算同步。

### 0.8 多轮脚本（禁止「发一句你好」代替）

手机侧多轮与发版表附录 A **同一套原文**（[production-acceptance-test-cases.md](production-acceptance-test-cases.md) 附录 A）。工作区必须有可读的 `README`/`README.md`，且允许跑一条打印 cwd 的命令（权限须能过审批或已是可写）。

| 轮 | 发送原文 | 本轮还要看到 |
| --- | --- | --- |
| 1 | `用一句话回复：你已连通，并给出一个三位数验证码。` | 连通语义 + 三位数；记下验证码 C |
| 2 | `刚才的验证码是多少？只回答数字。` | 数字 = C |
| 3 | `阅读工作区根目录的 README 或 README.md（若存在），用三句话总结它是什么产品。` | 读文件类工具卡；摘要与真实 README 相关；若弹出审批 → 走 S08 再继续 |
| 4 | `在工作区执行一命令打印当前目录名，把命令输出原样贴给我。` | 命令/终端类工具卡；输出含真实目录名；审批窗必须按 S08 测过至少一次允许 |
| 5 | `汇总：验证码、产品一句话、目录名各一行。` | 三行能与 1～4 核对 |

任一轮失败：记录轮次、手机时间线、桌面时间线、工具卡、审批截图。不得用「模型回了点什么」过关。临时目录场景：先在该目录放入最短 `README.md`（产品名一行即可）再跑 1～5。

## S. 交付场景套件（主门）

本轮只在 **T1**（适用时 **T2**）试飞。T3 整节 Deferred。每场要：视口截图、SYNC、切换后的真实对话。

### TC-MREM-S01 · 全表面布局走查 · P0 · 每轨 · 视口窄/标准/大

**步骤：** 按 §0.6 必拍表面。T1 真机用手机浏览器实际宽度；窄档用浏览器桌面设备模式缩到 360（**不要**为此去装 APK）。用手点：连接页主按钮、汉堡、发送、权限、模型、抽屉新会话、行 ⋯、审批（若本场无审批，与 S08 同场补拍）。

**期望：** §0.6 全部阈值满足。composer 一行上的 `+`、权限、（计划）、模型、发送 **互不重叠**，标签可读。Git 胶囊分支名与主操作在 360 宽仍能点开（允许 ellipsis，但点击打开的 sheet 里是全文）。抽屉不是「只有 ⋯」。

**Fail：** 「挤在一起但仍能碰巧点到」；发送与模型热区相交；审批按钮在安全区外点不到。

### TC-MREM-S02 · 远程同步基线（已有会话）· P0 · 每轨

**前置：** 桌面已有 ≥2 条带正式标题的活会话（不要只用空白新会话）。

**步骤：**

1. TC-MREM-201：`D = P`。  
2. 手机打开桌面 **当前选中** 的那条，等时间线加载完。  
3. SYNC(打开)。  
4. 对照桌面可见的最近 3 轮用户/助手文本（折叠工具卡允许，正文必须对得上）。

**期望：** 打开的是同一 `sessionId`；手机不是空白「新会话」hero（除非桌面该会话本来就是 blank）。标题栏标题 = 桌面侧栏该行标题。

### TC-MREM-S03 · 切换不同对话 · P0 · 每轨

**步骤：**

1. 打开会话 A，发 `这是会话A标记句。请只回复：ACK-A`。等 idle。SYNC(A)。  
2. 抽屉改开会话 B（另一条已有标题的会话）。确认时间线 **没有** `ACK-A` / `这是会话A标记句`。SYNC(打开B)。  
3. 在 B 发 `这是会话B标记句。请只回复：ACK-B`。SYNC(B)。  
4. 再切回 A。时间线仍有 A 的标记与 `ACK-A`，**没有** `ACK-B`。  
5. 桌面分别点 A、B，与手机一致。

**期望：** 切会话会换时间线与 composer 状态，不串台。失败必须清残行（卡上不变量），不得把 A 的气泡留在 B。

### TC-MREM-S04 · 已有工作区上的五轮对话 · P0 · 每轨

**前置：** 打开已有登记工作区里的一条会话（或新会话选该工作区）；工作区根有 README。该会话模型为 **Ayase `grok-4.6`**（§0.9）。权限不要停在纯只读，否则第 3～4 轮无法完成（先做 S07 切到工作区写入或完全访问）。

**步骤：** 按 §0.8 连续发送 1→5。每一轮 idle 后 SYNC(该轮)。第 3、4 轮若出现审批，执行 S08 的允许一次，再等该轮完成。

**期望：** 五轮在手机与桌面都成立。桌面项目侧栏该会话标题可随首轮更新（若 host 会改 title，则 D/P 一起变）。

**Fail：** 只完成第 1 轮；工具轮在桌面跑了手机看不到；或手机看到桌面没有。

### TC-MREM-S05 · 切换模型后再对话 · P0 · 每轨

**前置：** 该会话 `session.models` 至少两个可选模型（与桌面 ModelSelect 同一列表）。记下切换前模型 M1。

**步骤：**

1. 打开模型 sheet。布局：列表可滚、当前项可辨、点一项有选中态。  
2. 换成另一模型 M2（不要只打开 sheet 再关掉）。chip 须变成 M2 的产品文案（含 provider/model，不得停在「模型」）。  
3. SYNC(选模型)：桌面 ModelSelect = M2。  
4. 发送：`请只回复一行：当前模型切换验证-M2`。等 idle。  
5. SYNC(M2对话)：两边都有该用户句与助手回复。

**期望：** 这一轮按 M2 走（桌面会话的模型指示为 M2）。切回去 M1 再发 `切换验证-M1`，桌面回到 M1。

**Fail：** chip 点了没变、超时、只改手机本地；或切换后对话其实仍显示 M1。

### TC-MREM-S06 · 切换思考强度后再对话 · P0 · 每轨（模型无 reasoning 则 Blocked 并换一个有思考档的模型）

**步骤：**

1. 确认 chip 为 `模型 · <档>`。打开模型/思考 sheet，换一档 E2（如从 low→high，以桌面实际档名为准）。  
2. SYNC(思考)：桌面思考档 = E2。  
3. 发送：`请只回复一行：思考档切换验证`。SYNC。

**期望：** 无 reasoning 的模型 **不** 显示思考档（隐藏是对的）。有 reasoning 却永远停在「模型」无 effort → Fail。

### TC-MREM-S07 · 切换权限后再对话 · P0 · 每轨

**步骤：**

1. 打开权限 sheet：只读 / 工作区写入 / 完全访问 三项完整可见、可点（28×28）。记下切前预设 P1。  
2. 切到另一项 P2。chip 文案 = 该预设中文名。  
3. SYNC(权限)：桌面 Access = P2。失败必须回滚 P1 并有可见错误。  
4. 发送：`请只回复一行：权限已切换为P2`。SYNC。  
5. 若 P2 为只读：再发一条会写文件的请求，期望被拒绝或审批策略与桌面只读一致（记下，不强制破坏工作区）。

**期望：** 走 `/permission <id>`，不是本地假 `accessMode`。Plan 开启时另有计划 chip，点它走 S 内 `/plan off` 或并入本场。

### TC-MREM-S08 · 权限/审批窗口（手机条 + 桌面窗）· P0 · 每轨

桌面官方是审批/权限 **窗口或接管条**；手机是输入区上方审批条 + 允许/拒绝。两边都要「弹出来并能点完」。

**步骤：**

1. 权限设为会询问的档（工作区写入或完全访问，以桌面能弹出为准）。  
2. 发送会触发工具审批的一句，例如附录 A-4，或 `列出工作区根目录文件名`。  
3. **在审批出现的当秒** 同时截：手机审批条（标题、命令原文、允许一次、拒绝，按钮互不重叠、都在安全区内）；桌面对应权限/审批 UI。  
4. 手机点 **允许一次**。SYNC(允许)：桌面窗关闭，工具跑完，两边时间线有结果。  
5. 再触发一次审批，改在 **桌面** 点拒绝（或允许）。SYNC：手机条消失，结果与桌面一致。  
6. 再触发一次，手机点 **拒绝**。SYNC。

**期望：**

- 审批出现时 composer 发送不可用（§0.6 遮罩规则）。  
- 不是整页模态挡住无法关；也不是桌面弹了手机毫无反应。  
- 命令/工具名两边对得上。  
- 跨端解决后不得残留 pending。

**Fail：** 只有 toast、只有桌面有窗、按钮在屏外、点了无效果、或「审批在 DOM 里但用户看不见」。

### TC-MREM-S09 · 新对话 + 新工作目录 + 五轮 · P0 · 每轨

这是用户主路径，不能拆成「浏览过目录」和「别处说过话」两张 Pass。

**步骤：**

1. 在电脑上建空目录 `dshd-qa-ws-<日期>/`，放入一行 `README.md`（内容：`dshd-qa 临时工作区`）。  
2. 手机点 **新会话** → **浏览本机目录**（禁止系统选文件夹、禁止「请在电脑上选」）。布局：路径、上级、子目录、创建、确认互不重叠。

5. 在这个 **新 sessionId** 上跑完 §0.8 五轮；每轮 SYNC。第 4 轮目录名须为该临时目录名。  
6. 抽屉里这条新会话标题应出现在该工作区分组下（201 再跑一次）。

**期望：** 新目录、新会话、五轮对话、审批（若出现）、列表同步是 **同一条故事**。任一步 Fail 则本场 Fail，不得把 403 浏览成功和 S04 旧会话五轮拼成「新目录多轮已测」。

**清理：** 测完可在桌面 unlist 工作区；不要删用户其它仓。

### TC-MREM-S10 · 切会话后 composer 状态不串 · P1 · 每轨
