**Facts:** `dsh-base` always mounts `credentials-local` against `$DSH_HOME/.credentials.yaml`. `--skip-user-plugins` does not skip that row. function applyDesktopDshHome(env = {}) {
  const next = { ...env };
  for (const key of Object.keys(next)) {
