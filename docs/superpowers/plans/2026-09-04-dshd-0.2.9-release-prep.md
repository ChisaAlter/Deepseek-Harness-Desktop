## 背景与触发

- 用户报告（附件 `dshd-boot-20260903-230857.log` + 会话导出）：0.2.8 安装包
  （alpha.4 runtime）在旧投影缓存记录上**启动崩溃循环**——
  `session_projcache` 的 `identity` 缺 `isSeeded`/`inheritedEventCount`，
  storage-domain 严格校验抛 `invalid-record` → 插件树加载失败 → dsh 退出。
- 诊断：rc.1（已在 main，`bf42849791d`）的上游修复精确覆盖——
  `checkpointIdentity` 两字段改 optional + `compatibleVersions: [3,4]` +
  `invalidRecords: 'backup-and-skip'`（坏记录移作 `.bak` 冷重建，不再阻塞启动）。
  已用用户记录形状实证（临时 spec 2/2 过后删除）。0.2.9 即携带该修复的版本。
