# 远程 Web 与 Android 交互改造设计

日期：2026-09-06。状态：**approved / implementing**。
Feature：`mobile-remote`。本文件是提案，不替代已交付 Feature 卡或设计语言。

## 目标与范围

回应用户对远程 Web 弹窗和操作成熟度的不满，并将 Android 纳入同一次改造、构建和验收。深度借鉴指借用任务组织、状态管理、焦点和触屏行为，并转化为本项目实现与回归测试；不是安装一组 CSS 插件或搬运另一套皮肤。

继续使用同一份 `mobile/web`，Android 只负责扫码、系统媒体选择、WebView 承载与生命周期。不改 offer v2、sticky 存储键、host/Git 白名单或远程权限边界。Files、Diff、MCP、技能等已签字冻结能力不解冻；不增加原生聊天、PTY、任意文件写入、PWA 推送或离线发送队列。[契约](../../features/mobile-remote.md)

## 信息层级

| 表面 | 目标形态 | 返回与关闭 |
| --- | --- | --- |
| 聊天 | 常驻主页面；空会话也有导航和输入入口 | 根层不伪造历史，不拦截正常浏览器离开 |
| 会话列表 | 覆盖抽屉；分组、搜索、归档入口保留 | 选择成功收起；失败留在可重试处；不强制聚焦输入框 |
| 会话行菜单、附件来源、权限 | 短底部面板 | 明确关闭按钮、遮罩关闭；不叠多个同级面板 |
| 模型 | 可搜索的选择面板；长列表独立滚动；当前模型与思考强度保持可见 | 选中后在原面板反馈成功或失败，不为选择思考强度反复开关 |
| 设置 | 全屏目录到详情 | 左侧明确返回、右侧关闭；保留目录滚动和选中项 |
| 新会话与目录浏览 | 同一全屏任务内切步骤；路径、列表、确认区分离 | 返回上一步保留路径；目录上级与流程返回是不同动作 |
| Git 分支、提交、发布 | 同一全屏任务内的列表或表单 | 返回不重做操作；错误留在原表单；运行态可见且禁止重复提交 |
| 重命名、新建文件夹 | 当前任务内的短编辑步骤 | 返回原任务并保留上下文，不在底部面板上再堆第二个面板 |
| 删除、移除工作区等风险确认 | 单一确认层，指明对象和后果 | 取消不丢原表单；活会话仍无删除 |
| 审批 | 会话内的待处理区；长正文独立滚动、操作区可达 | 收起详情不等于拒绝或清除 pending；跨端解决后及时收起 |
| 图片详情 | 全屏灯箱 | 返回原附件或消息位置；不改变草稿和会话 |

设置只整理当前允许项，不照搬桌面设置能力。复杂任务用页面而非卡片网格；轻选择仍保留面板，不能把所有东西都改成全屏。

## 统一导航与返回

1. 共享导航状态是唯一真相，记录根会话、任务步骤、最上层确认或灯箱，以及返回目标。请求状态与业务对象继续归原有 host/Git 层所有。
2. 同级选择面板互斥；只允许一层有必要的确认或详情覆盖当前任务。背景不可点击和聚焦；关闭恢复到仍存在的触发器，文本输入框不因恢复焦点自动唤起键盘。
3. 屏幕返回、浏览器返回和 Android 返回都调用同一套可测试转换规则：最上层临时层、任务上一步、任务出口。软键盘出现时，系统返回优先收键盘，不同时关闭任务。
4. 浏览器 history 只保存无敏感数据的自有导航标记。不得保存 offer、deviceSecret、草稿正文或 RPC 参数；不得在前进、返回、刷新时重放发送、审批或 Git 写操作。
5. 明确 close 与 back：close 结束当前任务，back 退一步。关闭多步任务必须清理对应 history 条目，不能连续按返回还遇到已关闭页面。根层不得陷入拦截循环；前进只恢复合法视图或安全根页。
6. 切设备、新 offer、切会话时取消旧 UI 请求归属；迟到结果不得覆盖新页面。任务关闭不等于已经取消 host 的 Git 写操作，正在执行的状态必须仍可找回，不提供假取消。
7. 编辑草稿按会话保存；未提交任务字段在当前会话的返回过程中保留。只在用户明确丢弃、成功完成或失去业务对象时清理；不要每次返回都弹丢弃确认。

## 输入与阅读

- 常驻编辑元素不因普通重绘替换；保留内容、选区、输入法组合状态、附件和草稿归属。
- 手机回车换行，发送有明确按钮；运行态发送/排队和停止分别可达，以现有 host 能力为准，不伪造队列。
- 长草稿在用户离开编辑并阅读时可折叠，重新编辑恢复选区与滚动。点击模型、权限或附件控件不视为离开编辑后强制收键盘。
- 控件尺寸稳定；长模型名优先省略，完整名称可在面板中读取，不能只剩箭头。思考强度随实际模型能力显示，不以本地状态假装切换成功。
- 键盘、旋转和浏览器工具栏变化不能把发送或确认按钮移到可视区外。保持已有 viewport 像素回退，处理 visual viewport 的偏移，不把缩放当成键盘。
- 正文、代码、表格各自处理溢出；不禁双指缩放，不用全局手势截获破坏文字选择。抽屉拖动作为最后的渐进增强，按钮始终可用。

## Android 同步范围

- 保留稳定的 APK asset origin、requestId 防重入和 offer 消费后清理。新扫码覆盖旧请求，但旧响应不能回填新会话。
- 原生返回不再只依赖 canGoBack。优先请求共享导航处理；处理回调必须绑定 WebView 生命周期和请求代次，防双击导致连退或误退出。仅在明确根层时回到原生连接页；JS 未就绪或失败显示恢复状态，不重放旧配对历史。
- 采用窄的原生到当前可信页面调用，不新增任意 JS 到 Java 权限桥；返回与恢复不能扩张 host 白名单。外部链接继续系统打开。
- 明确 IME、安全区和状态栏由谁消费，避免 Compose 与 CSS 双重留白或不留白；同时验证三键导航和手势导航。
- 相册与拍照分别兑现。文件选择取消、拒绝、再次请求、旋转和销毁都恰好完成一次回调；拍照使用临时受控 URI，不增加广泛存储权限；迟到附件不能进入另一会话。
- 原生连接和权限页复用 DSHD token；缩短开发说明文案，保留必要错误、重试和权限说明。Android 触控目标与 Web 一并验收。
- 构建新的 APK，并校验内置 HTML/CSS/ESM 资源图与 Web 候选属于同一修订；不是把公网地址塞进 WebView。包名、asset origin 和已有配对保留；升级须采用同一签名且递增 versionCode。

## 设计语言落地前提

实施第一步先更新 `docs/design-language.md` 及对应英文文档的手机表面、触控命中区、编辑字号和返回控件约定，再改代码。动效使用现有 token 和 recipe；全屏页不加浮卡轮廓，短面板沿角色几何，颜色不新增平行表。实际测试触控区域 Web 至少 44 CSS px、Android 至少 48dp，图标可保持现有 16px；小屏输入字号拟为 16px，需先写入手机例外。不动画面板宽高，不增加动画库。

## 本轮验收与非目标

新一轮 T1 公网 Web、适用时 T2 LAN Web、T3 Android 均单独记录。历史文档的 T3 Deferred 仅代表旧轮次，不能继续作为本轮排除项，也不能倒填历史 Pass。

最低行为门槛：320/360/390/430 CSS px 与平板/横屏下关键按钮不遮挡；200% 文字或缩放可操作；返回一次只退一层；失败可重试且草稿不丢；五轮会话、审批、模型与思考切换、Git stacked 操作保持协议一致；新 APK 覆盖安装保留配对。真实设备、公开部署、签名密钥未验证时必须记未测或阻塞，不能以 fixture 截图顶替。

不在本轮新增功能大包、替换框架、升级 Harness、改桌面布局、开放远程管理权限、安装全部参考插件、修改系统网络或发布到应用商店。部署公网、覆盖用户 App 或使用发布签名需在交付关口确认，不由本设计文件代替操作授权。
