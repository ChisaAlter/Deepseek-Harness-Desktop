# 模块：dshbot 剥离与旧版迁移

桌面不维护或交付 dshbot 实现。插件源码、测试和发布职责属于独立插件；桌面不再含开发预置入口或市场第一方推荐。

## 旧版升级

`src/main/legacy-dshbot-preset.js` 只清除旧桌面写入的受管 patch 块和明确指向旧预置副本的链接。旧代码副本、机器人设置、房间 preset、记忆与会话均保留。真实用户安装（包括 pnpm 链接）以及 profile 依赖、bundles 不被此清理逻辑修改。

## 用户插件

新版 Harness 可能不兼容旧 dshbot。失败时由启动器的通用插件归因显示具体插件；单独禁用它即可停止装载，不卸载插件或删除数据。兼容版本准备好后可通过通用插件管理重新启用。不要用删除会话、清空配置或永久跳过全部插件作为升级方案。

## 维护边界

Harness 提供通用的插件会话展示契约：`session/presentation` 日志事件记录
`owner` 和 `title`，普通会话列表、搜索和空会话复用排除已归属会话；插件仍
通过原 Session ID 打开正常聊天界面。清除展示元数据恢复普通导航，用户显式
分叉不继承插件归属。此契约不授予工具权限，也不是访问控制或数据隐藏机制。
独立 dshbot 用它对齐固定联系人/群聊会话，桌面不因此重新预置插件。
集成门槛见 [plugin-session-navigation](../../features/plugin-session-navigation.md)。

会话展示可显式声明 `composer: 'managed'`，继续使用同一个编辑器，但由插件
通过 `conversation.input.managed` 提供资料配置入口，隐藏独立模型和开发配置
快捷控制。受管会话保留真实标题和根级面板/窗口控制，同时隐藏普通开发会话的
预设、轨迹、Session 日志、Git 分支与 Commit；历史视图状态不会让会话滞留在
已隐藏的轨迹页。该字段不改变工具授权。插件应用模型使用 `saveAsDefault: false`，
不修改普通会话默认模型；dshbot 的请求模型跟随规则仍由独立插件执行和测试。

- 本体测试旧预置脱离、普通插件启停、启动恢复和通用会话展示契约；机器人业务测试仍由独立插件维护。
- 旧版插件专属文档与 QA 是历史记录，不是本版产品承诺。
- 契约：[dshbot](../../features/dshbot.md)。
