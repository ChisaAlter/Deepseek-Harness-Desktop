# 模块：dshbot 剥离与旧版迁移

桌面不维护或交付 dshbot 实现。插件源码、测试和发布职责属于独立插件；桌面不再含开发预置入口或市场第一方推荐。

## 旧版升级

`src/main/legacy-dshbot-preset.js` 只清除旧桌面写入的受管 patch 块和明确指向旧预置副本的链接。旧代码副本、机器人设置、房间 preset、记忆与会话均保留。真实用户安装（包括 pnpm 链接）以及 profile 依赖、bundles 不被此清理逻辑修改。

## 用户插件

新版 Harness 可能不兼容旧 dshbot。失败时由启动器的通用插件归因显示具体插件；单独禁用它即可停止装载，不卸载插件或删除数据。兼容版本准备好后可通过通用插件管理重新启用。不要用删除会话、清空配置或永久跳过全部插件作为升级方案。

## 维护边界

- 本体只测试旧预置脱离、普通插件启停和启动恢复，不测试机器人功能。
- 旧版插件专属文档与 QA 是历史记录，不是本版产品承诺。
- 契约：[dshbot](../../features/dshbot.md)。
