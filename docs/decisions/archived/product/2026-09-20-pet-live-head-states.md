# Decision: 姿势立绘改为「无头身体 + THA4 活体头」逐帧合成

Status: implemented

Archived: 2026-09-20

中文 | [English](2026-09-20-pet-live-head-states.en.md)

## Problem

同日早些时候的 `pet-states-regen` 把十个姿势换成了高清静态立绘，用户验收否决：静态贴图与 THA4 活体渲染画风/比例不一致，且「其他动作不只是一个画面，要跟常规状态一样灵动」。即需求实为两点：常态活体输出要更锐利（糊）；动作状态要是真动画而非贴纸。

## Investigation

先实机探测模型能力边界，三条硬事实决定了方案：

1. **输出尺寸烘焙固定**：ONNX 契约 `[1,4,512,512]`，且实测喂 2.2× 放大的 `character.png`（绕头部参考点 256,128 缩放）输出 alpha bbox 不变（仍 ~124×172）——模型把角色渲染尺寸归一化到训练分布，喂大图无效。
2. **非标准姿势输入会坍缩**：把 `greet.webp`（举手姿势）作 `image` 输入，输出坍缩回标准站姿——蒸馏模型对姿势严重归一化，「换输入图换姿势」不可行。
3. **但 `image` 是逐帧运行时输入**：`session.run({image, pose})` 每帧都跑，且 still 层显示期间活体推理并未停——活头素材天然就在 `outCanvas` 里躺着。

重训高分辨率模型被排除：`C:\Ai\tha4` GUIDE 写明蒸馏训练 ~8-10h（RTX4080），且 THA4 师生链上限就是 512²——投入/收益不成立。

## Decision

**混合渲染升级为「姿势身体 + 活体头」**：

- `states/*.webp` 离线擦除头部区域（alpha-bbox 分数矩形 + 6px 羽化，原件备份在 `C:\Ai\pet-states-hd\states-with-heads\`），只保留身体/手臂/道具/尾巴。
- `drawStill` 在既有变换（物理摇摆 fx.rot/fx.sx/条带摆动）内，把 `outCanvas` 的头区（`HEAD_SRC`，512 帧内 x186-322/y56-196，含头发到领口）按 `STILL_HEAD[name]` 锚点（bbox 分数 [cx,cy,w]，高随 HEAD_SRC 宽高比推出）逐帧合成回立绘——所有状态继承眨眼、视线跟随、呼吸、头部微动，拖拽物理与悬挂锚定照常作用于合成头。
- `STILL_POSE[name]` 状态表情程序在 `stepPose` 末尾叠加：睡眠钉闭眼+头下垂+加深呼吸、进食咀嚼+视线压向饼干、摸头闭眼+头摆、庆祝闭眼笑+弹跳、生气竖眉+高频头抖等；立绘激活期间（alpha>0.4）idle 小动作/点按反应/困倦下垂全部让位，避免程序打架。
- 常态输出清晰度：推理帧 alpha bbox 内做有界 unsharp mask（k=0.45，只写 alpha>96 像素的 RGB——透明区模型会吐垃圾 RGB，轮廓 alpha 渐变带不动所以不产生外晕），实测眼部/轮廓明显变锐。

## Alternatives considered

- **高分辨率重训/重导出 THA4**：师生链 512² 封顶 + ~10h GPU 训练，否决。
- **喂姿势图当模型输入**：实测坍缩回标准姿势（见 Investigation 2），否决。
- **姿势图切层做骨骼动画（mini-Live2D）**：单图无法可靠分层（遮挡面需 inpaint），投入远大于收益，否决。
- **全部状态改纯 pose 程序 + 道具/粒子（不要身体立绘）**：跑步腿、拎起悬空、蜷缩睡姿这类整体轮廓变化 pose 空间表达不了，字面度损失太大；保留身体立绘 + 活头是两全解。
- **第二级 SR 模型（waifu2x 类 ONNX）**：能带来真细节，但引入新二进制依赖 + 每帧二次推理；先上无依赖的 unsharp，SR 留作后续可选升级。

## Consequences

- 十个姿势全部「活了」：面部永远与常态同源同风格（就是同一模型输出），零风格漂移；身体姿势保持字面表达。
- 重生成 `states/` 资产的工序变更：生成图后必须按 `decapitate.py` 擦除头部并标定 `STILL_HEAD` 锚点，否则双脸/断头——已写入 feature 卡 invariant。
- 新增渲染成本：每帧一次 ~24k 像素 unsharp（<0.5ms）+ 一次 head drawImage，可忽略。
- 残留瑕疵：立绘身体是清晰赛璐璐风、头是软水彩风，1× 显示尺寸下接缝不显眼；若用户仍不满意可再生成软画风身体（管线不变）。
- 旧决策 `2026-09-20-pet-states-regen` 中「静态立绘」部分被本决策取代（资产管线与提示词仍有效，只是多一步擦头）。
