# Decision: 启动页使用三段响应式仪器画布

Status: implemented

Archived: 2026-09-26

中文 | [English](2026-09-25-boot-page-responsive-instrument-canvas.en.md)

## Problem

启动页的状态区与日志区使用视口绝对定位，中央内容始终垂直居中。故障详情增加时，这些区域无法根据窗口剩余高度协调空间；恢复跳板也只看 `error` 状态，自动重启仍在排程或执行时会过早出现。

## Decision

把既有启动页内容排为顶部状态区、中央启动区和底部日志区三行。中央区在空间充足时垂直居中，内容过多时独立滚动；四个既有恢复动作允许折行。日志区使用随视口高度缩放的固定上限，从顶部裁去旧内容并保留最新日志。短窗减少留白和日志区高度。

保留仪器画布、鲸鱼加载资源、品牌、状态来源、日志格式、现有 IPC 动作、主题隔离、窗口圆角与 BrowserView 覆盖行为。插件进度只显示 controller 或插件事件提供的实际状态。恢复跳板只有在 `error` 且恢复状态不为 `scheduled` 或 `restarting` 时显示；不增加控制、面板或合成进度。

## Alternatives considered

保留中央 Flex 居中并继续用视口绝对定位状态和日志：在短窗与较长故障详情同时出现时没有行高约束，也无法让中央诊断独立滚动。

把诊断和恢复动作迁到新卡片或启动器专用面板：会增加一套 boot 界面并重复已有 Recovery Board 的职责，与整窗仪器画布及既有恢复路径不符。

## Consequences

布局由三行 CSS Grid 管理，中央诊断区拥有独立滚动范围，短窗仍能访问恢复动作。日志保留有界高度和最新行优先规则。窄宽度下动作可能分多行显示。源码和文档合同同步；本次未运行自动化测试或检查运行时画面。
