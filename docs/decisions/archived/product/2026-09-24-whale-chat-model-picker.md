# Decision: 鲸鱼娘聊聊卡内展开模型与思考选择

Status: implemented

Archived: 2026-09-24

中文 | [English](2026-09-24-whale-chat-model-picker.en.md)

## Problem

248px 的「聊聊」卡原来把模型名和推理强度塞在一条薄文字行，用原生 `select` 弹出操作系统菜单。当前选择缺少层级，模型 provider 只在原生分组中可见，英文档位在中文界面显得突兀；长模型名也难以辨认。

## Decision

线程下方保留一条发丝分隔，放两枚紧凑选择入口：小标签说明模型或思考，下层呈现当前值，完整模型名保留悬停提示。点开时在卡片内部展开列表；模型按 provider 分组，思考档位按目录真实 id 选择但显示中文名，当前项勾选，列表限高滚动。新选择写入同一常驻会话；重复点当前项只收列表，不重写选择或把思考档位复位。不改变后端目录或模型语义。Escape 优先收起列表，下一次再关卡；卡片继续按真实高度跟随角色定位。

## Alternatives considered

- **继续使用原生下拉，只加边框和间距** — rejected：选项弹层仍脱离卡片视觉，中文档位和 provider 分组的呈现无法稳定控制。
- **打开主会话的完整模型设置面板** — rejected：这张卡用于桌面上快速说一句话，跳转会打断当前输入；现有 ↗ 已提供进入完整会话的路径。

## Consequences

模型和思考选择更易扫描，也可通过键盘操作。列表展开时卡片变高，需要按现有身体锚点重新定位并限制列表高度；实际目录 id、保存通道和聊天历史不变。
