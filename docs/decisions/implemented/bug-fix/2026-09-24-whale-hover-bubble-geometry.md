# Decision: 鲸鱼娘命中与气泡共用真实绘制几何

Status: implemented

中文 | [English](2026-09-24-whale-hover-bubble-geometry.en.md)

## Problem

鲸鱼娘使用覆盖整块显示器的透明窗口。窗口进入交互态时，透明像素也会挡住下方应用的点击。主进程在身体轮廓外再加 24px 热区；渲染器在 live 姿态渐入后把用于清除残影的宽大方框当成身体命中范围。长按拖起后，同一方框还使气泡远离头部或错误地翻到下方。

## Decision

主进程的即时交互余量与渲染器退出迟滞都收至 8px。live 模型的命中盒按 `drawLive` 的足部或抓取点、旋转、缩放和镜像变换计算实际 alpha 盒；用于清除残影的方框只用于清屏。气泡以身体盒定位，状态卡或聊天卡不改变它的头部锚点。拖拽期间仍保持交互态，保证松手事件能到达。

## Alternatives considered

- **只缩小主进程余量** — rejected：睡觉、拖拽等 live 姿态仍会向主进程上报宽大的清屏方框，气泡位置也不变。
- **用逐像素 alpha 判定窗口命中** — rejected：透明窗口的命中开关作用于整窗，逐像素数据仍需跨进程同步；逐帧读取图像会增加推理路径负担。

## Consequences

相邻应用的可点击区域扩大，拖拽气泡跟随当前头部。快速摆动的极端帧可能比原来的宽热区更早穿透，但拖拽守卫和 200ms 边缘防抖继续保护手势。回归测试覆盖主进程余量、拖拽气泡和旋转姿态盒。
