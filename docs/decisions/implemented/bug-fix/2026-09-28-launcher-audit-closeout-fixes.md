# Decision: 启动器收尾审计的数据保全、恢复取消与界面可达性修复

Status: implemented

中文 | [English](2026-09-28-launcher-audit-closeout-fixes.en.md)

## Problem

2026-09-28 外部 `audit-closeout/REPORT.md` 确认 A1–A6、U1–U2：MCP/设置/凭据的读取错误被当成空数据、文件发布可部分覆盖或跟随链接；旧插件恢复可在停止或导入后复启；Electron 错误日志被过滤且单行可超过缓存预算；插件覆盖安装验证失败会删掉原安装；缩放压扁导入列表，恢复标题偏离角色字号。U3 是长确认框压力风险。

前置决策审计：[导入事务整改](2026-09-28-import-transaction-and-launcher-remediation.md) 与本次部分重叠，保留其目录事务和维护槽设计；[桌面能力桥](../architecture/2026-09-26-upstream-desktop-bridges.md) 保留诊断采集架构，本次修正事件契约和容量边界。两篇均不被取代；其余市场和恢复产品路径保持现行契约。

## Decision

1. MCP、设置、凭据的目标读取仅将 ENOENT 视为空；其余错误中止对应写入。文件发布使用同目录随机独占临时文件、完整写入后原子替换，拒绝文件链接及父路径链接；发布失败保留原字节并清理本次临时文件。
2. 插件恢复归属于启动世代。停止、取消和关闭使旧恢复失效；异步恢复在副作用边界检查所有权，并与导入共享维护准入。
3. console tail 接受真实 Electron 的字符串 `error`，兼容旧数值级别；超长单行按 UTF-8 完整字符保留末尾，缓存总字节始终受预算约束。回归既检查类行为，也检查真实 Electron 事件到实际报告文件的链路。
4. 插件安装前保存覆盖前状态；CLI 或验证失败恢复原安装，不以卸载覆盖包代替回滚。恢复失败必须显式报错并保留可恢复备份。
5. 先更新双语设计语言：恢复标题为 16/24；导入正文至少 120px，空间不足时外层纵向滚动；确认卡按视口限高、正文独立滚动，标题与按钮不收缩。
6. 真实 Electron 回归覆盖明暗主题、默认/最小窗口、100%–200% 浏览器缩放、展开说明、逐项勾选与导入按钮命中，以及 600 字符和超长确认正文。测试只用隔离窗口和只读 IPC 数据，不操作真实用户导入、插件或安装器。

## Alternatives considered

- 只把直接写改成 rename：能防部分发布，但不能防读错清空和固定临时链接，拒绝。
- 只在启动器显式按钮入口检查维护锁：容易实现，但旧恢复任务仍能绕过同一边界，拒绝。
- 验证失败后重新联网安装旧插件：备份更小，但离线失败、版本漂移和依赖变化会破坏原工作状态，采用本地快照恢复。
- 增大最小窗口或缩小字号：可掩盖当前几何，但不能覆盖缩放与展开说明；采用可滚动的内容约束。

## Consequences

读取或路径校验失败会明确拒绝导入，保留已有数据。安装快照增加磁盘与复制成本，换取无需联网的恢复。日志超长部分会被截断，但不留下破损 UTF-8。小视口下可能出现内外两层滚动，换取逐项选择和操作的可达性。

验证范围不等于发布验收：故障注入与 CLI 替身不证明真实 pnpm 安装或断电行为；布局断言使用 Chromium 几何与命中测试，截图不代表人工审美或完整键盘验收。
