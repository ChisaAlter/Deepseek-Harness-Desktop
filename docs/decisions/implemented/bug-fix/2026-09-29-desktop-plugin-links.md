# Decision: 内置插件链接的幂等准备

Status: implemented

中文 | [English](2026-09-29-desktop-plugin-links.en.md)

## Problem

实装启动先后报告 task-control、platform-session 和 usage-panel 链接 EEXIST。有效链接被反复删建，且存在性探测吞掉所有读取错误，可能把原始故障掩盖成创建冲突。独立重建压力测试未复现用户环境触发条件；不能把本次防御修复等同于已解释所有现场故障。

## Decision

- 共用链接准备逻辑复用已解析到同一目录的 junction；目录身份比较兼容 Windows 路径大小写。只将 ENOENT 视为缺失，其余错误原样传播。
- 仅替换符号链接，不递归删除占位普通目录或文件；usage-panel 原有已识别旧副本的隔离与回滚协议保留。
- 创建遇 EEXIST 后重新检查，仅当占位项确为指向预期目录的链接时接受；未知内容、错误目标和无法核验的链接仍阻断启动，不跳过任务保护。

## Alternatives considered

直接忽略 EEXIST 会接受错误插件；清空 node_modules 会破坏用户内容；反复重试所有文件系统错误会掩盖访问故障。以上均不采用。继续每次删建有效链接没有收益，反而扩大冲突窗口。

## Consequences

有效链接启动时不再改写。未知占位内容需单独处理，不能静默删除。回归覆盖有效链接、读取失败、并发创建、错误目标、断链及用户内容保留；现场安装版仍须在后续候选中复验。本次不改安装文件、不发布。
