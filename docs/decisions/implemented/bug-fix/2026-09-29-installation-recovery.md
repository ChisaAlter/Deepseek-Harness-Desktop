# Decision: 安装等待、下载与运行时解压的恢复边界

Status: implemented

中文 | [English](2026-09-29-installation-recovery.en.md)

## Problem

最初的安装卡住反馈没有现场日志。随后收到的 WER 记录 Whale Isle 0.3.3.0 在 Windows 10 19045 上发生 AppHangB1，但没有线程堆栈，不能将故障归因到某个调用。代码审查和故障注入确认：整包下载只有总超时，安装子进程失败仍等待注册表，同版本修复无法证明成功却等待八分钟，解压没有超时且会提前删除旧运行时。首次解压落在用户数据盘，安装目录所在盘的空间不能代表它的可用空间。

既有决策审计：[独立分发](../../proposed/architecture/2026-09-24-launcher-standalone-distribution.md) 部分重叠，保留线路与校验权威；[运行时实例布局](../architecture/2026-09-28-runtime-instance-layout.md) 部分重叠，保留链接清单格式；[差量更新](../product/2026-09-17-electron-updater-differential-updates.md) 部分重叠，保留现有 updater 通道；[启动器收尾](2026-09-28-launcher-audit-closeout-fixes.md) 涉及插件安装，不能替代桌面 Setup 的恢复边界。没有完全取代或需要归档的记录。

## Decision

- 整包下载使用连接 20 秒、无数据 45 秒和全程两小时的独立预算；暂态网络错误或指定 HTTP 错误最多三次，从头重试并清理半成品，等待重试期间也可取消。现有 electron-updater 通道保持十五分钟预算。
- 下载反馈使用真实字节、速度与重试次数，每秒最多约四次常规进度通知；未知大小不显示百分比。下载目标盘按响应大小加 256 MiB 预留检查，解压目标盘按未压缩 tar 大小的 115% 加同等预留估算。检查不代表写入不会失败，文件系统不支持探测时不冒充零空间。
- 完整 Setup 仅在重新通过当前发布清单的 SHA512 校验后复用；新下载写入 `.part`，校验通过才进入正式缓存。取消安装向导或安装前准入失败保留已验证缓存。旧发行缺失校验清单仍须明确确认，不复用未验证缓存。
- 安装程序启动失败及时返回错误，自更新只在操作系统接受 spawn 后退出。spawn 在任务保护协调器 commit 内执行，失败会释放 Host 接纳锁且不锁定 committed。等待阶段明确要求完成向导并留意系统授权；失败优先于注册表变化。同版本父进程结束只返回未确认，不把时间戳或 UAC 父进程退出当成安装完成。
- 解压在独立临时目录进行，每五秒报告耗时，十五分钟超时，停止桌面会取消正在进行的提取。提取子进程关闭后才清理临时输出。旧运行时在新树校验成功前保留，目录替换失败回滚，`.previous` 保存中断替换的恢复基线；Windows 绝对 junction 在正式路径重建后才写完成戳。同一目标的提取串行化，遗留临时树在下次启动清理，当前活动临时树不清理。
- 界面沿用现有启动器进度卡与 boot 日志 ticker；不新增安装皮肤、虚构百分比或自动绕过 Windows 授权。
- 启动路径的链接校验、修复和清理使用真正的异步文件 I/O，根 realpath 在每次操作内复用；打包脚本保留同步 API，共享清单验证。每五秒通过既有日志报告已完成链接数、总数和耗时。准备阶段在文件操作之间检查取消，不把取消当作损坏而重新解压；正式目录替换开始后完成链接重建或回滚，再退出，避免取消留下半成品。保留路径边界与实体目录保护。

## Alternatives considered

- 只增大超时：可容忍慢盘和慢网络，但会把断流与已失败的安装拖得更久，因此采用分阶段预算与明确终态。
- 看到同版本 exe 或父进程退出就宣告成功：反馈快，但无法区别修复失败和 UAC 交接，因此只报告未确认。
- 删除旧运行时后原地解压：峰值空间较小，但损坏归档会同时破坏恢复基线，因此接受临时目录额外空间。
- 直接续写上次的部分下载：节约带宽，但需要可靠的 ETag、Range 和来源身份协议。本次只复用重新验证的完整文件；部分下载重试从头开始。
- 给同步链接循环包一层 Promise：接口看似异步，但仍阻塞主线程，因此逐项等待文件系统的异步 API；不引入跨启动缓存跳过链接验证，以免遗漏损坏或被移动的 junction。

## Consequences

用户更早获知断流、空间不足和安装失败；首次解压有活动提示且失败保留原运行时。临时解压需要额外磁盘空间；同版本修复仍无可信安装完成回执，因此明确保留未确认状态。未修改 NSIS 静默安装语义、签名策略、发布包名称或用户会话目录。

回归覆盖断流、重试、取消、未知长度、校验失败、完整缓存、安装失败与同版本修复、低空间、损坏归档保留旧树、目录链接搬迁以及超时/取消等待提取进程关闭。源码与故障注入证据不能替代同一 CI Setup 的 Windows 安装验收，也不能断言原用户问题已解决。

链接追加回归覆盖慢 I/O 期间事件循环让出、取消不触发重新解压、链接重建失败后的回滚、越界路径/父 junction 拒绝与真实目录保留。异步化改善响应能力，不保证总准备时间缩短，也不能中断已经提交给操作系统的单次文件 I/O；取消在该操作返回后生效。
