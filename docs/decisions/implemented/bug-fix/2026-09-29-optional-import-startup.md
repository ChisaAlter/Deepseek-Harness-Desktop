# Decision: 可选导入不抢占冷启动

Status: implemented

中文 | [English](2026-09-29-optional-import-startup.en.md)

## Problem

空桌面会话加上共享技能就触发导入 hold，新用户即使开启自动启动也会被送到导入页；上次启动失败的首页诊断也被此条件覆盖。用户要求直接进入桌面而非迁移引导。

## Decision

冷启动不调用可选来源探针；正常自动启动直达桌面，关闭自动启动或上次失败时明确显示首页。中断导入恢复、恢复错误与未决 journal 仍强制停在导入页，手动导入和只读来源保护不变。

## Alternatives considered

- 仅排除共享技能可减少误触，但官方来源中任何可选内容仍会抢占启动，不采用。
- 完全跳过导入恢复可始终启动，却会在未决事务上写入，不采用。
- 记录用户已跳过标记可兼容旧引导，但新增持久状态且首次仍抢占，不采用。

## Consequences

导入必须由用户主动发现，不能再依赖首次弹出引导。回归覆盖可导入来源、失败首页、关闭自动启动、来源不可读以及导入恢复阻断。安装版需重新构建才能获得此行为。
