# Decision: Git 状态不可用时隐藏标题栏操作组

Status: implemented

中文 | [English](2026-09-23-hide-unavailable-git-titlebar.en.md)

## Problem

会话没有工作目录，或 Git 状态读取尚未完成、返回 `null`、抛错时，标题栏仍绘出禁用的 Commit、空分支和可打开的下拉。下拉没有可执行内容，窄窗口里还会留下细白条；整组占位也加重右栏展开后的拥挤。

## Decision

`ui-git` 仅在当前会话有工作目录、该目录的状态已载入且状态对象有效时绘制 Git 标题栏操作组。载入完成状态绑定到 cwd，切换目录的第一帧也不会短暂绘出前一个仓库的控件。已确认 `isRepo:false` 仍绘制「初始化 Git」。有效仓库即使当前快速动作禁用，也保留分支和菜单，因为其中仍可查看状态或执行其他动作。状态读取失败仍由既有的窗口焦点和工作区登记信号重试，恢复后自动显示控件；进度反馈不依赖标题栏是否可见。

## Alternatives considered

- **只隐藏禁用的 Commit**：空分支、分隔线和下拉仍会留下无用占位及细白条。
- **所有快速动作禁用时隐藏整组**：干净仓库仍有可用分支和菜单，隐藏会阻断这些入口。
- **状态不可用时显示「初始化 Git」**：`null` 也可能是授权或 IPC 错误，不能据此判定非仓库。

## Consequences

状态加载期间标题栏短暂不留 Git 占位，加载成功后按当前密度出现。不可用状态不显示 Git 下拉；有效仓库及非仓库初始化路径保持原功能。`git-actions.client.spec.tsx` 覆盖无目录、加载中、切换 cwd、`null`、IPC 拒绝、工作区登记后恢复及非仓库初始化。
