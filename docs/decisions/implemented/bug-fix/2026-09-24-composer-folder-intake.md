# Decision: 输入栏拒绝文件夹后只提交普通文件

Status: implemented

中文 | [English](2026-09-24-composer-folder-intake.en.md)

## Problem

输入栏识别粘贴或拖放中的文件夹后会显示拒绝提示，但仍把原始文件列表交给 `addFiles`。因此文件夹可能继续进入附件处理；混合批次中的普通文件也无法可靠地独立处理。

## Decision

输入栏按目录元数据把文件夹从批次中剔除，保留现有文件夹拒绝提示，只把普通文件交给 `addFiles`。纯文件夹批次不调用附件入口；混合批次仍处理普通文件，并可在同一提示中呈现文件夹与普通文件的拒绝原因。附件入口维持单参数文件列表接口。

## Alternatives considered

- **把文件夹及目录集合传给 `addFiles`**：将输入栏已经判定的拒绝责任转移给附件入口，且现行接口只接收文件列表。
- **拒绝整个混合批次**：会阻止用户添加同批次中有效的普通文件。

## Consequences

文件夹不会流入附件处理；有效文件仍可添加。输入栏定向测试覆盖粘贴文件夹、混合拖放以及同批次的多条拒绝提示。
