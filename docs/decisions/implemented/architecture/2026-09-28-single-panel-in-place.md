# Decision: 单一右栏原位工作环

Status: implemented

中文 | [English](2026-09-28-single-panel-in-place.en.md)

> Supersedes [2026-09-27-empty-state-upstream-guide](../../archived/product/2026-09-27-empty-state-upstream-guide.md)

## Problem

入口卡片位于经典 surfaces 列，点击却打开另一条 dock 列并收起原列。用户确认保留当前外观，移除第二套右栏，入口和内容原位切换。

## Decision

只挂载一个全高右栏容器，以 Sidebar 的页签/资源生命周期管理所有上游功能，保留 DSHD 320px 两列卡片、窗口顶部页签、关闭键在标题右侧和窗口控件避让。移除经典栏体的挂载和双向互斥切换；文件、Office、浏览器、终端链接和标题栏统一指向同一所有者。关闭最后内容页签原位恢复 guide。mini 打开可以保留当前展开状态。

## Alternatives considered

- 只取消切换动画：成本小，但仍有两套宽度、页签和入口状态，无法解决结构问题。
- 只把旧五类功能留在经典栏：容易保留外观，但不能容纳远程文件和上游新类型。
- 重新实现全部页签与资源生命周期：可完全定制，但重复上游能力、扩大维护面。

## Consequences

入口和内容共享栏宽、页签与开合状态，保留上游资源能力。经典组件源代码暂留供既有类型与历史测试引用，但产品运行时不再挂载第二栏；旧布局宽度不再占用另一条网格轨。旧经典栏的页签和未保存缓冲区不自动迁移。新增路由、末页返回与 mini 不抬栏回归测试。

验证：相关包 88 文件 / 1128 测试通过，统一入口新增回归 8/8；`apps/web` 类型检查与最终完整源码构建通过，Electron 已重启。源码 Electron 中 Files / Browser / Diff / Agents 原位开关，连续帧的 x=1027、width=542、y=0 保持不变，旧宿主数量为 0，末页关闭回到 guide；重启后 1440px 窗口再验四入口，x=898、width=542 全程稳定，文件树与真实 Git 差异可用，标题栏几何门禁通过。governance 6/6、首轮 doc-sync 8/8；复跑时并行修改的标题栏决策缺配对记录且 design-language 超预算，降为 6/8。全量 GUI 仍有其他区域失败；桌面契约 25/26，唯一未通过的是既有 input-trigger 源码文本标记过期，未将其记为本轮通过。

记录审计：完全取代 2026-09-27 空态镜像决定的跨栏打开方案；2026-09-23 外观恢复决定部分重叠，保留其视觉约束；跨会话与 Browser guest 交接决定继续适用。
