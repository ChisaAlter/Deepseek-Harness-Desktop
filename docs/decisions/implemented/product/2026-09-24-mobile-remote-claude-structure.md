# Decision: 手机远程改用 Claude 式页面结构

Status: implemented

中文 | [English](2026-09-24-mobile-remote-claude-structure.en.md)

## Problem

手机远程 Web 与 Android 内置 SPA 过去被规定为桌面 Harness 的窄屏重排：顶栏、抽屉、InputBar、popover 菜单都照搬桌面几何，并明令禁止贴底大圆角面板和分组卡片。结果是手机端读起来像被压窄的桌面页：抽屉同时承担导航、搜索和完整目录，输入区是桌面工具行，模型与权限选择是悬在输入框上的小菜单。用户要求参照 Claude 移动端重做 Web 与 Android 页面，同时保留 DSHD 的浅色／深色配色。

## Decision

- [设计语言「手机远程交互」](../../../design-language.md#手机远程交互)改为：**页面结构**参照 Claude 移动端，**颜色、字体栈与明暗**仍只取 `--dsw-alias-*` / `--dsw-specific-*` 同值表。桌面端不受影响。
- 结构要点：48px 顶栏（菜单／Git 胶囊或标题／新会话）；空白草稿居中显示鲸标与问候；常驻输入为 20px 圆角浮动卡，32px 圆钮与胶囊；抽屉只放一级导航（会话／工作区／设置）、「最近」单行会话、电脑头像与「新会话」主胶囊；完整会话列表改为从「会话」进入的全屏任务；设置为分组卡片，顶部是电脑卡和工作区卡。
- 由输入框触发的选择（附件来源、模型、思考强度、权限）改为底部面板，模型面板首层列当前提供方的模型并提供下钻；顶栏与列表行的菜单仍是贴近触发器的 Menu，破坏性确认仍是居中 Modal。
- 尺寸取 Claude 截图实测值后再收紧一档（普通按钮 32px、整行按钮 40px、列表行 40～54px），命中区用透明扩展补足 Web 44px／Android 48dp。
- Android 原生只重排连接、相机权限与扫码页；聊天界面仍是同一份 `mobile/web`，协议、配对、导航层级与 sticky 行为不变。

## Alternatives considered

- **完全照搬 Claude（暖纸面、衬线标题与正文、陶土色标记）**：与截图最接近，但另起一套色板和字体，与桌面端看起来像两个产品；中文衬线在部分 Android WebView 回退为宋体。原型评审中用户明确要求保留自家配色，故拒绝。
- **工作台结构（首页即最近会话卡片、无抽屉、贴底通栏输入、模型与权限整页内联）**：对编程任务的状态可见性更好，但与 Claude 和桌面端都拉开距离，交互路径需要重新学习；原型评审选择了 Claude 结构，故拒绝。
- **维持桌面窄屏重排、只调尺寸**：改动最小，但保留抽屉过载和桌面式菜单，达不到用户要求的移动端观感，故拒绝。

## Consequences

- 收益：手机端层级更浅，抽屉只做导航；模型、思考强度与权限在同一底部面板完成；控件尺寸统一且更紧凑。
- 代价：手机端不再与桌面组件一一对应，今后桌面原语改版不会自动映射到手机；手机专属几何由本节设计语言维护。旧的「桌面几何」测试断言随之改写为新合同。
- 完整会话列表从抽屉迁到全屏任务，返回层级新增一层，统一返回决策需覆盖。
- 评审原型（假数据，含被拒的工作台结构变体）保留为 [mobile-claude-redesign.html](../../../superpowers/prototypes/mobile-claude-redesign.html)，不进 APK、不由手机服务器提供；[手机远程卡](../../../features/mobile-remote.md)记录现行合同。
