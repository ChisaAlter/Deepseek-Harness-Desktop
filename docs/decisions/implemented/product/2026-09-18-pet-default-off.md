# Decision: 桌宠默认关闭

Status: implemented

中文 | [English](2026-09-18-pet-default-off.en.md)

## Problem

用户反馈桌面启动后卡顿掉帧。桌宠默认启动透明窗口和神经动画，不能假设每台电脑都有充足的渲染余量；尚未实测确认它是全部卡顿的唯一原因。

## Decision

配置默认值与管理器归一化统一为仅 enabled=true 才开启。缺失或畸形值关闭，保留已有明确开启的配置、设置和托盘入口。关闭时清除成长扫描定时器，沿用已有窗口关闭、光标轮询停止与日志尾随停止路径；在途扫描允许完成。

## Alternatives considered

- 全局关闭功能旗标可彻底隐藏功能，但会移除用户主动开启的入口，故不采用。
- 强制覆盖所有已保存的 true 可保证所有旧安装关闭，但会丢弃明确选择，故保留显式配置。
- 降帧或更换渲染管线可能减少开销，但超出本次默认开关调整，不实施。

## Consequences

默认启动不创建桌宠窗口、不加载其动画页面，也不启动桌宠周期扫描。手动开启仍恢复原有功能；已开启过的安装需手动关闭一次。既有扫描线程在关闭时不强制终止，在途请求可完成。本次不承诺其他界面特效或整体帧率问题已解决。

此前的 [扫描移出主线程](../bug-fix/2026-09-17-pet-growth-scan-off-main-thread.md) 与 [托盘勾选同步](../bug-fix/2026-09-18-tray-pet-checkbox-resync.md) 仍有效，本决定只调整默认状态和停止周期扫描，不取代它们。
