# Decision: 取消桌面仓库文档字数门禁

Status: implemented

中文 | [English](2026-09-29-remove-doc-word-limits.en.md)

## Problem

维护系统为四份核心文档设置固定字数上限，必要的契约补充也会导致 `doc-sync` 失败。用户明确要求取消此限制。

既有记录审计：[透明窗口 OS 圆角遮罩修复](../bug-fix/2026-09-27-transparent-window-os-corner-mask.md)部分重叠，曾将设计语言上限提高到 14400；该产品修复继续有效，其字数上限由本决定取消。历史计划和验收日志保留当时事实。

## Decision

移除桌面仓库 `doc-sync` 中的字数门禁，删除对应校验脚本、预算清单和专用测试。四份文档均不再受固定字数限制；维护总览、检查技能与 hook 注释同步更新。此维护流程变更不改变产品契约，不新增 feature 卡，也不修改 vendor 的上游治理。

## Alternatives considered

- 提高现有上限：可以暂时放行，但仍会阻挡后续必要内容，不符合取消限制的要求。
- 改为非阻塞警告：保留了长度提示，但继续维护用户已取消的固定阈值，因此不采用。

## Consequences

文档长度不再使本地或 CI 的桌面 `doc-sync` 失败。决策格式、归档、feature 卡、规则同步、链接与双语配对检查继续执行；内容精简由编辑判断负责。门禁不再自动提示长文档。
