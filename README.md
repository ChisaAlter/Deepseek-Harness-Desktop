# dshbot

Standalone DeepSeek Harness plugin: sidebar bot contacts and group rooms.

**Source currently lives in the desktop monorepo** (not yet migrated here):

- https://github.com/ChisaAlter/Deepseek-Harness-Desktop/tree/main/vendor/dshbot

Install today:

```bash
dsh plugin --profile web add github:ChisaAlter/Deepseek-Harness-Desktop#path:/vendor/dshbot
```

Or after npm publish: `dsh plugin --profile web add dshbot@<semver>`
